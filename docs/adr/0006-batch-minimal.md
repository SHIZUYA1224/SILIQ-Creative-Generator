# ADR 0006 — CSV一括生成（最小版）

状態：採用（Phase 3の一部を前倒し）／2026-10-10

## 決定

`siliq-render batch` と `job-runner` crate で、テンプレート×CSV行×版のPNGを一括生成する。

### データ
- CSVは自前の厳格なparserで読む（依存追加なし）。RFC 4180のサブセットで、UTF-8のみ（BOMは除去）。
- 値は1文字も変えない（trimなし、数値変換なし、先頭0は維持、数式は評価しない）。
- 列は `rowId` と、テンプレートのslot idだけ。未知の列、必須slotの列欠落、重複rowId、ファイル名に使えないrowIdはエラー。
- 必須slotの空欄はエラー。任意slotの空欄はテンプレートの値のまま。
- 差し込むのはslotが宣言した属性（`text.value`／`assetId`）だけ。位置・色・書体は変えない。

### 処理順（error policy `block-all`）
1. 計画：テンプレート検証、CSV検証、版の存在と承認、出力名の展開と検査（`{rowId}`・`{variantId}` 以外の置換は不可、重複・既存ファイルはエラー）。
2. 全件を出力先内の一時ディレクトリーへ描画し、全issueを行・版・ノード付きで集める。
3. 1件でもエラーなら一時ディレクトリーを消し、**何も公開しない**。
4. 全件成功したら `hard_link` で公開（上書きしない）。最後にmanifestを書く。

### 固定snapshot
`ResourceStore` は一度照合したbytesを保持し、同じジョブの中では再読込しない。ジョブ中に素材ファイルが差し替わっても混入しない（BAT-003）。

### manifest
テンプレート・データのSHA-256、行数、版、RenderProfile、font backend、各出力の `rowId`・`variantId`・ファイル名・SHA-256・寸法・`inputDigest`（テンプレートhash＋版＋行の値）・文字ごとの採用サイズ・警告。時刻は含めない（同じ入力ならmanifestもbyte一致する）。

## 未実装（今回の範囲外）
- キャンセル、障害後の再開、失敗分だけの再実行（BAT-004）
- 「正常な行だけ出力」モード（`completed_with_errors`）
- 並列実行（現在は逐次）
- UTF-8以外のエンコーディング、JSONデータ、列名の対応付けGUI
- 画像slotへの外部ファイル取り込み（現在はテンプレートに登録済みの素材idだけ指定できる）
